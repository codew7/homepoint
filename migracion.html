🔄 Migración Firebase RTDB

Mueve registros de pedidos/ a nodos por año — procesamiento 100 % local en el navegador

1 Conexión a Firebase
Firebase Console → Realtime Database → panel principal (URL al tope)
Firebase Console → Configuración del proyecto → Cuentas de servicio → Database secrets
¿Cómo obtengo el Database Secret?
  1. Abrí Firebase Console y seleccioná tu proyecto
  2. Hacé clic en el ícono de engranaje ⚙ → Configuración del proyecto
  3. Seleccioná la pestaña Cuentas de servicio
  4. Expandí la sección Database secrets (parte inferior)
  5. Hacé clic en Mostrar junto al secret existente y copialo
Nota: Los Database Secrets son considerados legacy por Firebase pero siguen siendo válidos para acceso administrativo a Realtime Database. El secret otorga acceso completo: tratalo como contraseña.

Seguridad: Este valor nunca sale de tu navegador — todas las llamadas van directamente a tu-proyecto.firebaseio.com.
2 Seleccionar año a migrar
Por defecto la operación es solo copia. Marcá esta opción únicamente si querés liberar espacio en el nodo original.
3 Vista previa
⚠️ Modo MOVER activado. Los registros migrados serán eliminados de pedidos/. Esta acción no se puede deshacer. Asegurate de tener un backup.
