Vinculá el WhatsApp del local

  1. En el celular del local abrí WhatsApp.
  2. Tocá ⋮ (o Configuración) → Dispositivos vinculados.
  3. Vincular un dispositivo y escaneá este código.

El código se renueva solo cada pocos segundos.

Falta la clave de Firebase

Elegí el archivo .json de la cuenta de servicio del proyecto de WhatsApp (Firebase → Configuración del proyecto → Cuentas de servicio → Generar nueva clave privada).

Hay otra copia conectada

Otro programa tomó la conexión de este WhatsApp (por ejemplo, la versión anterior en otra PC). Cerrala y tocá Reiniciar conexión.
