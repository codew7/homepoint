Vinculá el WhatsApp

  1. En el celular del abrí WhatsApp.
  2. Tocá ⋮ (o Configuración) → Dispositivos vinculados.
  3. Vincular un dispositivo y escaneá este código.

El código se renueva solo cada pocos segundos. Si se escanea con otro número, se rechaza.

Falta la clave de Firebase

Elegí el archivo .json de la cuenta de servicio del proyecto de WhatsApp (Firebase → Configuración del proyecto → Cuentas de servicio → Generar nueva clave privada). Es una sola clave para todas las líneas de esta PC.

Hay otra copia conectada

Otro programa tomó la conexión de este WhatsApp, por ejemplo esta misma línea abierta en otra PC. Una línea funciona en una sola PC a la vez: cerrala allá (o quitala) y tocá Reiniciar conexión.
